# Cartoon Studio

Make cut-out cartoon shorts and memes in your browser: write a script, and the characters talk (AI voices or your own),
lip-sync, pose, walk and react. Export vertical 1080×1920 videos for TikTok, Reels and Shorts.

- Runs entirely in the browser — no server, no account.
- Installable as an app (click **Install app** in the top bar, or the install icon in the address bar).
- AI voices use [Kokoro](https://huggingface.co/onnx-community/Kokoro-82M-v1.0-ONNX) via
  [kokoro-js](https://www.npmjs.com/package/kokoro-js) (Apache 2.0), running locally.

## Script example

```
# title: Me when the alarm rings at 6AM ⏰
# bg: bedroom
# cast: hero, devil, angel

hero (sleepy) [cross]: Ugh... the alarm again.
devil (angry) [zoom]: Five more minutes. You deserve it.
hero (shocked) [handsup shake]: IT'S 11 AM?!
```

Open **How to write a script** in the Script tab for every option.
